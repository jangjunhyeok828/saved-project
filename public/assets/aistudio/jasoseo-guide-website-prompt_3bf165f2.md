# 자소서 작성 가이드북 웹사이트 제작 프롬프트

> 사용법: 이 파일 전체를 Google AI Studio의 **Build** 화면 입력창에 붙여 넣으세요.
> 결과를 본 뒤 수정할 점은 같은 대화에서 한 가지씩 요청하면 됩니다. (맨 아래 "후속 수정 요청 예시" 참고)

---

## 1. 역할과 목표

너는 한국어 교육용 웹사이트를 만드는 시니어 프론트엔드 개발자이자 UX 디자이너야.
아래 **5장 콘텐츠**를 바탕으로 취업준비생이 자기소개서를 처음부터 끝까지 쓸 수 있게 돕는 **한 페이지짜리 가이드 웹사이트**를 만들어줘.

- 대상: 자소서를 처음 쓰거나 서류에서 자주 떨어지는 20~30대 취업준비생
- 사용 환경: 대부분 **휴대폰**으로 보고, 노트북에서 실제 작성 작업을 함
- 핵심 경험: "읽고 끝"이 아니라 **따라 하면서 채워 넣는** 가이드

## 2. 기술 조건

- React + TypeScript + Tailwind CSS로 만들어줘.
- **서버, 로그인, 외부 API, Gemini API 호출은 쓰지 마.** 순수 정적 사이트로 동작해야 해.
- 콘텐츠(본문, 표, 프롬프트, 체크리스트, 출처)는 컴포넌트에 흩어 쓰지 말고 `content.ts` 한 파일에 데이터로 모아줘. 나중에 내용만 고치기 쉽게.
- 사용자가 입력하거나 체크한 값은 `localStorage`에 저장해. 저장·불러오기는 try/catch로 감싸서 실패해도 페이지가 깨지지 않게 해.
- 한글 폰트는 Pretendard를 CDN으로 불러와 써줘. (`https://cdn.jsdelivr.net/gh/orioncactus/pretendard/dist/web/static/pretendard.css`)

## 3. 화면 구성과 기능

### 3-1. 전체 레이아웃
- **상단 히어로**: 제목 "자소서 작성 가이드북", 한 줄 요약(5장 0번), "1단계부터 시작하기" 버튼.
- **목차 내비게이션**: 데스크톱은 왼쪽 고정 사이드바, 모바일은 상단 고정 바에서 펼치는 메뉴. 현재 읽는 섹션을 강조 표시.
- **진행 표시줄**: 화면 맨 위에 스크롤 진행률 바.
- 섹션 순서는 5장 콘텐츠 순서를 그대로 따라줘.

### 3-2. 인터랙티브 기능 (꼭 넣을 것)
1. **5단계 진행 스테퍼**: 1~5단계 섹션 위에 단계 번호 스테퍼를 두고, 각 단계에 "이 단계 완료" 버튼. 완료 상태는 저장.
2. **워크시트 입력칸**: 5장의 '분석 결과 한 장 정리' 표, '경험 × 역량 매트릭스', '문항 해석 표'는 사용자가 직접 입력할 수 있는 칸으로 만들어줘. 매트릭스는 행(경험) 추가·삭제 가능, 칸을 누르면 ○ 표시가 토글.
3. **체크리스트**: '고른 소재 점검'과 '제출 전 체크리스트'는 체크박스로. 체크 상태 저장, "모두 지우기" 버튼, "11개 중 8개 완료" 같은 진행 표시.
4. **프롬프트 복사 버튼**: AI 프롬프트 코드 블록마다 오른쪽 위에 "복사" 버튼. 누르면 "복사됨" 피드백.
5. **고치기 전/후 비교**: 4단계 예시는 탭 또는 토글로 "고치기 전"과 "고친 후"를 전환해서 보여줘.
6. **근거 펼쳐보기**: 표의 '근거' 내용과 통계 출처는 본문을 길게 만들지 않도록 접었다 펼 수 있게.
7. **내 작업 내보내기**: 사용자가 입력한 워크시트 내용을 텍스트(.txt)로 내려받는 버튼 하나.
8. **인쇄용 스타일**: 브라우저 인쇄 시 내비게이션과 버튼은 숨기고 본문만 깔끔하게 나오게.

### 3-3. 디자인
- 차분하고 신뢰감 있는 톤. 흰 배경, 진한 남색 계열 강조색 하나, 회색 보조색. 그라데이션·과한 그림자·이모지는 쓰지 마.
- 본문 글자 16px 이상, 줄간격 1.7 이상. 모바일에서 표는 가로 스크롤되게 하고 글자가 잘리지 않게.
- 각 섹션 맨 위에 "이 섹션의 핵심" 한 문장을 강조 박스로.
- 다크 모드 지원(시스템 설정 따름).
- 접근성: 버튼과 입력칸에 레이블, 키보드로 모든 기능 사용 가능, 색 대비 충분히.

## 4. 반드시 지킬 규칙

- **5장의 문장, 숫자, 출처를 바꾸거나 새 통계·사례를 지어내지 마.** 요약하거나 꾸미기 위해 내용을 추가하지 마.
- 출처 링크는 모두 새 탭으로 열리게 하고, 페이지 맨 아래 '출처' 목록을 그대로 유지해.
- 가상 사례에는 "(설명을 위한 가상 사례)" 표시를 지우지 마.
- 특정 기업 로고, 실존 인물 사진, 외부 이미지를 쓰지 마. 필요하면 단순한 아이콘(lucide-react)만.
- 푸터에 "이 가이드는 공개 자료를 정리한 참고용이며, 지원하는 회사의 채용공고 안내가 항상 우선합니다." 문구를 넣어줘.

## 5. 콘텐츠 (웹사이트에 들어갈 내용 전체)

### 0. 한 줄 요약
기업은 스펙보다 직무와 이어진 경험을 보고, 한 사람의 서류를 5분 안쪽으로 읽습니다. 그래서 자소서는 **직무 경험 하나를, 결론부터, 행동과 숫자로** 쓰는 글입니다.

**이 가이드북 쓰는 법**
1. "평가자는 무엇을 읽나"에서 5가지 원칙을 먼저 익힙니다.
2. 1~5단계를 순서대로 따라 한 문항을 완성합니다: 문항 해석 → 직무·회사 분석 → 소재 고르기 → 문단 구조 → 문장 쓰기.
3. 문항 유형에 맞춰 "문항별 작성법"을 참고합니다. 공공기관이라면 "블라인드·NCS 규칙"도 확인합니다.
4. "AI 활용"은 각 단계를 빠르게 하는 보조 도구로 씁니다.
5. 제출 전 체크리스트로 점검합니다.

### 1. 평가자는 무엇을, 얼마나 읽나
**핵심:** 인사담당자 10명 중 9명은 직무 경험을 가장 중요하게 보고, 6명은 한 사람의 이력서·자소서를 5분 안에 검토합니다.

| 자료 | 대상 | 핵심 결과 |
| --- | --- | --- |
| 고용노동부 2023년 하반기 기업 채용동향조사 (2024.03 발표) | 매출 500대 기업 315곳 | 직무능력이 중요하다 96.2% vs 학교·전공·학점 등 스펙 36.2%. 신입 채용 결정 요소 1위는 직무 관련 일경험(35.6%). 면접 중심 전형 92.1% |
| 인크루트 인사담당자 설문 (2023.07) | 인사담당자 475명, 표본오차 ±4.5%p | 직무 경험을 가장 비중 있게 평가 90.1%. 지원자 1명 서류 검토 5분 미만 62.3%. 자소서 평가를 유지하겠다 85% 이상 |
| Sackett 외, Journal of Applied Psychology (2022) | 인재 선발 도구 메타분석 | 구조화 면접이 직무 성과를 가장 잘 예측(타당도 .42, 1위). 비구조화 면접은 .19 |
| Nielsen Norman Group 시선 추적 연구 (2006, 2017 재확인) | 웹 사용자 232명 | 화면의 글은 처음 몇 줄과 각 문단의 첫 단어 위주로 훑어 읽음(F자 패턴) |

**5가지 작성 원칙**
1. **직무 경험이 주인공입니다.** 어떤 문항이든 지원 직무와 이어지는 경험으로 답합니다. 스펙 나열은 이력서에 맡깁니다.
2. **결론을 첫 문장과 소제목에 둡니다.** 5분 안에 훑어 읽는 사람에게 끝까지 읽어야 알 수 있는 글은 불리합니다.
3. **행동을 장면이 보이게 씁니다.** 자소서는 면접 질문의 재료가 되고, 구조화 면접은 과거 행동을 물어 검증합니다. 도로교통공단의 NCS 자소서 작성 안내도 "읽는 사람이 당시 상황을 그릴 수 있도록" 쓰라고 요구합니다.
4. **이 회사, 이 직무에만 맞게 씁니다.** 회사명만 바꾼 복사형 글은 감점 1순위로 꼽히고, AI 작성을 허용하는 기업도 다른 지원자와 내용이 겹치면 감점합니다.
5. **사실만, 면접에서 말할 수 있는 것만 씁니다.** 고용노동부 고용24 작성 가이드는 과장·거짓을 금지하고, 공공기관은 기재한 경력·경험을 검증 대상으로 봅니다.

(근거 메모) F자 패턴 연구는 웹페이지 독자 대상이어서 자소서 평가자에게 그대로 들어맞는다는 증거는 아닙니다. 다만 짧은 검토 시간과 함께 보면 두괄식을 받치는 근거가 됩니다.

### 2. 1단계 · 문항 해석
**핵심:** 문항은 '보려는 역량 + 답해야 할 요소 + 형식 조건'으로 쪼개고 시작합니다. 자소설닷컴이 2026년 4월 정리한 감점 유형 3위가 문항의 핵심 키워드에 답하지 않는 '동문서답형'입니다.

**실제 문항으로 본 해석 예시** — 도로교통공단 NCS 자소서 문항(2023)
> 시키는 일의 범위를 넘어서 적극적으로 도전한 경험이 있다면 소개해 주십시오. (450자 이내) — 언제, 어떤 상황이었습니까? / 어떻게 행동했습니까? / 결과에서 얻은 교훈은 무엇입니까?

| 분해 항목 | 이 문항에서는 |
| --- | --- |
| 보려는 역량 | 주도성 — 지시받지 않은 일을 스스로 찾아서 했는가 |
| 답해야 할 요소 | ① 언제·어떤 상황 ② 내 행동 ③ 결과와 교훈 (하나라도 빠지면 동문서답) |
| 핵심 키워드 | '시키는 일의 범위를 넘어' — 본문에서 원래 맡은 일과 더 한 일을 구분해 보여줘야 함 |
| 형식 조건 | 450자 이내, 경험 1개 |

다른 문항에도 같은 표를 채워 보세요. 특히 **기간 조건**(예: "최근 5년 내에 직면했던 어려움")과 **복수 질문**(지원동기와 포부를 한 문항에서 묻는 경우)을 놓치기 쉽습니다.

**문항에 하위 질문이 없을 때**는 대부분 위 세 요소(상황·행동·결과)를 기대한다고 보면 됩니다. NCS 자소서 양식들이 "상황·행동·결과 중심으로 구체적으로 기술하시오"처럼 같은 틀을 반복해서 요구합니다.

[인터랙티브] 사용자가 자기 문항을 입력하고 4개 분해 항목을 채우는 입력 표.

### 3. 2단계 · 직무·회사 분석
**핵심:** 쓰기 전에 '평가자의 단어'를 모읍니다. 고용24 작성 가이드는 업무 용어를 직무기술서에서 가져오라고 안내합니다. "왜 이 회사인가"는 직접 조사한 사실이 있어야 쓸 수 있습니다.

| 무엇을 | 어디서 | 어떻게 쓰나 |
| --- | --- | --- |
| 요구 역량·업무 용어 | 채용공고의 담당업무·자격요건·우대사항, 공공기관은 공고에 함께 올라오는 NCS 직무기술서 | 문단 첫 문장과 소제목에 그 용어를 그대로 씁니다 |
| 직무의 실제 업무 단위 | NCS 홈페이지(https://www.ncs.go.kr)의 해당 직무 '능력단위' | 내 경험 중 그 업무와 닮은 부분을 고르는 기준이 됩니다 |
| 회사가 지금 하는 일 | DART 전자공시(https://dart.fss.or.kr) 사업보고서의 '사업의 내용', 회사 IR·보도자료 | 지원동기에 최근 사업 1~2개를 구체적으로 언급합니다 |
| 인재상·핵심가치 | 채용 홈페이지 | 협업·가치관 문항의 소재를 고를 때 맞춥니다 |

**분석 결과는 한 장으로 정리해 둡니다.**

| 항목 | 내 메모 |
| --- | --- |
| 요구 역량 3~5개 (공고 표현 그대로) | (입력) |
| 이 직무가 매일 하는 일 2~3가지 | (입력) |
| 회사의 최근 사업·이슈 2개 (출처) | (입력) |
| 그 사업에서 내가 맡고 싶은 역할 | (입력) |

AI는 공고 문구를 정리하는 데는 유용하지만, 회사의 최근 사정을 정확히 알려주지는 못합니다. GPTers 실험에서도 '이 회사여야 하는 이유' 항목은 AI로 고쳐도 20점 만점에 8점 이하에 머물렀습니다.

[인터랙티브] 위 '내 메모' 칸은 입력 가능 + 저장.

### 4. 3단계 · 소재 고르기
**핵심:** 문항마다 직무와 가장 가까운 경험 하나를 고릅니다. 고용노동부 조사에서 기업이 선호한 일경험은 3~6개월 장기 인턴십(74.0%)과 기업 프로젝트 참여·성과 제출(68.9%)이었습니다. 그런 경험이 없다면 아르바이트·동아리·팀 프로젝트에서 직무와 닮은 장면을 찾습니다.

**① 경험 인벤토리 만들기** — 지금까지의 활동을 빠짐없이 적습니다. 공공기관 지원서는 둘을 나눠 적게 하니 처음부터 구분해 두세요.
- **경력:** 금전적 보수를 받고 일한 것 (인턴, 아르바이트, 계약직)
- **경험:** 보수 없이 한 활동 (팀 프로젝트, 동아리, 공모전, 봉사, 실습)

**② 경험 × 역량 매트릭스** — 2단계에서 뽑은 요구 역량을 열로, 내 경험을 행으로 놓고 증명할 수 있는 칸에 ○를 표시합니다.

| 내 경험 | 역량 A | 역량 B | 역량 C | 역량 D |
| --- | --- | --- | --- | --- |
| 경험 1 | | | | |
| 경험 2 | | | | |
| 경험 3 | | | | |

○가 많은 경험이 주력 소재입니다. 같은 경험을 두 문항에 쓸 때는 문항이 보려는 역량에 맞는 다른 장면을 꺼냅니다. ○가 하나도 없는 역량은 빈칸으로 남겨두고, 면접 전까지 보완할 거리로 삼습니다.

**③ 고른 소재 점검** — 아래에 모두 "예"여야 쓸 만한 소재입니다.
- 내가 맡은 역할을 한 문장으로 말할 수 있다
- 내가 한 행동이 두세 개 이상 떠오른다
- 결과를 기준이 있는 숫자로 말할 수 있다 (없으면 변화를 구체적으로)
- 면접에서 꼬리질문을 받아도 사실대로 답할 수 있다

### 5. 4단계 · 문단 구조 짜기
**핵심:** 결론을 먼저 쓰고(두괄식), 그 근거를 상황·행동·결과(STAR) 순서로 붙입니다. 짧게 훑어 읽는 평가자는 첫 줄에서 내용을 파악하고, 면접관은 행동 부분을 바탕으로 질문합니다.

**문항 하나의 기본 틀**

| 순서 | 쓸 내용 | 분량 |
| --- | --- | --- |
| 소제목 | 역량 키워드 + 결과를 한 줄로 | 1줄 |
| ① 결론 | 무엇을 해서 어떤 결과를 냈고, 그것이 어떤 역량인가 | 1문장 |
| ② 상황·과제 (S·T) | 내가 맡은 역할, 해결해야 했던 문제와 그 크기 | 2~3문장 |
| ③ 행동 (A) | 내가 한 일 2~3가지와 그렇게 판단한 이유 | 가장 길게 |
| ④ 결과 (R) | 기준이 있는 숫자, 배운 점 | 1~2문장 |
| ⑤ 직무 연결 | 입사 후 어떤 업무에서 이 방식을 쓸지 | 1문장 |

글자수가 짧아도(300~500자) ①③④는 빼지 않습니다. 줄일 때는 ②와 ⑤를 먼저 줄입니다.

**고치기 전과 후** (설명을 위한 가상 사례, 문항: 주도적으로 문제를 해결한 경험)

고치기 전:
> 저는 책임감이 강하고 적극적인 사람입니다. 대학 시절 카페 아르바이트를 하며 다양한 고객을 만났고, 업무 효율을 높이기 위해 많은 노력을 했습니다. 이를 통해 주도성을 기를 수 있었습니다.

고친 후:
> **[주문 대기 12분→7분] 지시 없이 바꾼 제조 동선**
> 피크타임 주문 대기를 줄이려 제조 동선을 제안·적용해, 3개월간 평균 대기를 12분에서 7분으로 줄였습니다. 매장은 점심에만 주문이 몰려 대기 불만이 리뷰에 반복됐지만, 제 역할은 주문 접수를 맡은 아르바이트생이었습니다. 먼저 2주간 주문별 제조 시간을 재어 병목이 얼음·컵 위치에 있다는 것을 확인했습니다. 점장님께 기록을 보여드리고 도구 배치를 바꾸는 안을 1주일 시범 운영했습니다. 바뀐 배치는 사진과 함께 매뉴얼로 남겨 다른 근무자도 따르게 했습니다. 문제를 감으로 말하지 않고 기록으로 설득하는 방식을 생산관리 업무에서도 쓰겠습니다.

달라진 점: 책임감·주도성 같은 형용사를 빼고, 행동(기록·제안·시범 운영·매뉴얼화)과 기간이 붙은 숫자로 주도성을 보여줍니다. '지시 없이'라는 문항 키워드도 소제목에 들어갔습니다.

[인터랙티브] 고치기 전/후를 탭으로 전환.

### 6. 5단계 · 문장 쓰기 규칙
**핵심:** 좋은 문장은 평가자가 확인할 수 있는 사실을 담습니다.

| 규칙 | 피할 문장 | 이렇게 | 근거 |
| --- | --- | --- | --- |
| 추상어는 사례로 증명 | "열정과 소통, 성실함을 갖춘 인재입니다" | 그 단어를 빼고 그 태도가 드러난 행동을 씁니다 | 자소설닷컴 감점 유형 4위(추상어를 사례 없이 나열) |
| 주장에는 근거를 | 의견·포부만 있는 문단 | 주장 바로 뒤에 경험이나 성과를 붙입니다 | 감점 유형 '근거 부족 주장 나열형' |
| 숫자에는 기준을 | "매출을 30% 올렸습니다" | 기간·모수·비교 대상을 붙입니다: "3개월간 월평균 200만 원에서 260만 원으로" | 고용24(성과는 수치로), GPTers(모수·예산·기간 없으면 검증 불가) |
| 업무 용어는 공고에서 | 내가 만든 표현 | 채용공고·직무기술서의 용어를 씁니다 | 고용24 작성 가이드 |
| 시행착오도 쓰기 | 매끄럽기만 한 성공담 | 막혔던 점과 바꾼 판단을 한 문장 넣습니다 | 감점 유형 2위 '완벽한 AI 스타일형' |
| 번호·일반론 피하기 | "첫째, 둘째, 셋째", "이를 통해 OO 역량을 길렀습니다" | 경험의 흐름대로 쓰고, 배운 점은 바뀐 행동으로 보여줍니다 | 무하유가 공개한 AI 작성 자소서의 특징 |
| 회사·직무명 확인 | 다른 회사 이름이 남은 글 | 지원할 때마다 고유명사를 다시 확인합니다 | 감점 유형 1위 '복사 & 붙여넣기형' |

**상투어 바꾸기**

| 피할 표현 | 바꾸는 방향 |
| --- | --- |
| 귀사에 기여하겠습니다 | 입사 후 맡을 업무와 거기서 쓸 내 기술을 명시 |
| 최선을 다했습니다 | 한 일, 들인 시간·횟수 |
| 소통의 중요성을 깨달았습니다 | 그 뒤 달라진 내 행동 한 가지 |
| 어릴 때부터 꿈이었습니다 | 이 직무에 관심을 갖게 된 구체적 계기 |

(근거 메모) 자소설닷컴 감점 유형은 컨설턴트의 첨삭 사례를 정리한 것이고 통계는 아닙니다. 다만 인사담당자 설문(직무 경험 중시)과 연합뉴스 취재(내용이 겹치면 감점)와 방향이 같아 함께 실었습니다.

### 7. 문항별 작성법
**핵심:** 분량과 공은 경험 문항에 가장 많이 들입니다. 인크루트 설문에서 인사담당자들이 '빼도 된다'고 많이 꼽은 문항이 입사 후 포부(48.6%)와 성격의 장단점(24.4%)이었습니다. 이 두 문항은 화려하게 쓰기보다 짧고 구체적으로 쓰면 충분합니다.

| 문항 | 평가자가 보는 것 | 구조 | 피할 것 |
| --- | --- | --- | --- |
| 직무역량·경험 | 이 일을 해본 적이 있는가 | 4단계 기본 틀 그대로 | 경험 여러 개 나열 |
| 지원동기 | 왜 이 회사, 왜 이 직무인가 | 회사의 최근 사업(사실) → 그와 이어지는 내 경험 → 입사 후 맡고 싶은 업무 | 회사 칭찬, 공고 문구 베끼기, 어느 회사에나 맞는 문장 |
| 협업·갈등 | 내가 팀 안에서 한 행동 | 갈등의 원인 → 내가 한 커뮤니케이션 행동 → 결과 | 감정 묘사, 상대 비난 |
| 실패·극복 | 책임감과 배우는 방식 | 내가 통제할 수 있었던 실수 → 수습 행동 → 그 뒤 바뀐 일하는 방식 | 남·환경 탓, 실패 같지 않은 실패 |
| 성장과정·가치관 | 일하는 태도의 뿌리 | 지금의 태도를 만든 계기 하나 → 그것이 드러난 최근 행동 | 어린 시절부터 시간순 나열, 가족 소개 |
| 입사 후 포부 | 직무 이해와 현실감 | 입사 초기에 익힐 것 → 1~3년 안에 맡고 싶은 업무 → 기여, 단계마다 기한 | "최고의 전문가가 되겠습니다" 같은 다짐 |
| 성격의 장단점 | 일하는 방식 | 장점 하나 + 드러난 사례 / 단점 하나 + 보완하는 구체적 방법 | 장점 같은 단점, 사례 없는 형용사 |

**가치관·포부 문항은 특히 직접 쓰세요.** 무하유가 2023년 하반기 자소서 26만여 건을 분석했을 때, 미래 계획·가치관을 묻는 문항의 AI 사용 의심 비율(33.7%)은 일반 문항(평균 3% 내외)보다 훨씬 높았습니다. 비슷한 글이 몰리는 문항이라는 뜻입니다.

**공공기관(NCS) 자소서**는 일대기식 성장과정 대신 지원동기, 조직 적합성(핵심가치·인재상), 직업기초능력을 묻는 문항으로 구성됩니다. 대부분 경험 문항이므로 4단계 기본 틀을 그대로 씁니다.

### 8. 블라인드·공공기관(NCS) 작성 규칙
**핵심:** 직무와 관계없는 개인정보는 쓰지 않습니다. 블라인드 채용에서는 간접적으로 드러나도 위반이 될 수 있습니다.

**법이 정한 기준** — 채용절차법 제4조의3(2019 신설)은 상시 30명 이상 사업장이 직무에 필요하지 않은 아래 정보를 자소서 등에 요구하지 못하게 합니다. 요구하지 않았는데 스스로 쓸 필요도 없습니다.
- 용모·키·체중 등 신체적 조건
- 출신지역·혼인여부·재산
- 부모 등 직계 존비속과 형제자매의 학력·직업·재산

**공공기관 블라인드 채용** — 학교명, 가족관계, 출신지역 등을 암시하는 내용도 금지하는 경우가 많고, 위반하면 감점·불합격될 수 있습니다. 한국예술인복지재단의 블라인드 위배 기준 안내가 제시한 예시입니다.

| 쓸 수 있는 것 (직무능력 정보) | 쓰면 안 되는 것 | 간접 노출 예 |
| --- | --- | --- |
| 전공, 학위, 자격증, 직장명, 담당업무, 수상 기록 | 학교명, 연령, 성별, 출생지, 가족사항, 종교, 신체조건 | "행정병으로 복무하며"(성별), "월드컵 당시 중학생이던"(연령) |

이 기준은 기관마다 조금씩 다릅니다. 같은 학교명도 어떤 기관은 마스킹(OO대학교)을 요구하므로, 공고의 작성 유의사항을 먼저 읽으세요.

**경력·경험기술서 쓰는 법** — 도로교통공단 채용 안내(2023) 기준

| 구분 | 쓸 내용 순서 |
| --- | --- |
| 경력 (보수를 받은 일) | 직무 영역 → 수행 내용 → 본인의 역할과 구체적 행동 → 주요 성과 |
| 경험 (직무 관련 기타 활동) | 수행한 활동 내용 → 조직 안에서의 역할 → 활동 결과 |

기재한 경력·경험은 증빙 서류로 검증하는 기관이 많습니다. 증명할 수 있는 날짜·기간으로 쓰세요.

### 9. AI로 작성 돕기
**핵심:** AI는 생각을 꺼내고 점검하는 데 쓰고, 경험·회사 사실·최종 문장은 직접 책임집니다. 연합뉴스가 2025년 확인한 대기업·공기업 중 가장 많은 5곳이 허용한 범위도 문장 교정이었고, 2곳은 AI 사용 자체를 금지했습니다.

| 단계 | AI에게 맡길 일 | 직접 할 일 |
| --- | --- | --- |
| 1 문항 해석 | 문항을 역량·요소·조건으로 분해 | 분해 결과 확인 |
| 2 직무·회사 분석 | 공고에서 요구 역량 뽑기(원문 인용) | 회사의 최근 사업 조사 |
| 3 소재 고르기 | 질문을 던져 경험을 STAR로 정리 | 사실대로 답하기 |
| 4·5 구조·문장 | 맞춤법·문장 다듬기, 글자수 줄이기 | 초안 쓰기 |
| 제출 전 | 엄격한 채점, 예상 면접 질문 | 지적받은 부분 내 말로 고치기 |

**모든 프롬프트에 넣을 안전장치** (복사 버튼)
```
- 내가 준 재료에 없는 경험·숫자·사실은 만들지 말고 (확인 필요)로 표시해.
- 칭찬은 하지 말고 문제점부터 말해.
- 정보가 부족하면 먼저 나에게 질문해.
```

**① 경험 재료 추출 (3단계)** (복사 버튼)
```
너는 취업 컨설턴트야. 자소서는 쓰지 말고 질문만 해.
내 경험 메모: [두서없이 적은 경험]

- 상황·역할·행동·결과·배운 점을 채울 수 있도록 한 번에 하나씩, 10개 이내로 질문해.
- 결과에는 숫자를 물어보고, 숫자에는 기간·모수·비교 대상을 물어봐.
- 끝나면 [상황 / 역할 / 행동 / 결과 / 배운 점] 표로 정리해.
```

**② 엄격한 채점 (제출 전)** — 메모리를 끄고 새 대화창에서 합니다. (복사 버튼)
```
너는 하루에 자소서 수백 장을 읽는 [기업명] [직무] 서류 심사자야.
[채용공고] [문항 원문] [내 자소서]

1) 첫 3초 판정: 계속 읽을지, 넘길지와 이유.
2) 문항 적합성 / 직무 연관성 / 숫자·구체성 / 이 회사여야 하는 이유 / 문장·분량을 각 20점 만점으로 채점.
3) 탈락 사유 3가지를 해당 문장을 인용해 제시.
4) 지금 재료만으로 가능한 수정안과, 재료가 더 필요한 부분을 나눠서.
```

**③ 면접 질문 예측 (제출 전)** (복사 버튼)
```
너는 [기업명] [직무] 실무 면접관이야. [제출할 자소서]
- 가장 약한 지점을 파고드는 질문 10개와 각 질문의 의도를 적어.
- 답하지 못하면 탈락 위험이 큰 질문 3개를 표시해.
```

AI 채점 점수는 실행할 때마다 달라지고 합격 기준도 아닙니다. 총점보다 항목별 점수와 탈락 사유를 보세요.

### 10. 기업은 AI 자소서를 어떻게 보나
**핵심:** AI를 쓴 사실보다, 내 경험 없이 AI가 대신 쓴 글이 불이익을 받습니다. 허용 범위는 회사마다 다르니 공고의 안내를 먼저 확인하세요.

| 시점 | 자료 | 내용 |
| --- | --- | --- |
| 2026.01 | 무하유 2026 AI 채용 트렌드 리포트 | 자사 탐지기 기준 AI 작성 의심 자소서 2024년 48.5% → 2025년 64.4%. 탐지기 판매사의 자체 수치이고 판정 기준은 비공개 |
| 2025.11 | 고용노동부 2025년 기업 채용동향조사 (500대 기업 396곳) | 채용에 AI를 쓰는 기업 21.7%, 도입·확대 계획 74.5%. AI를 쓴 청년의 77.2%가 자소서·이력서 작성에 사용 |
| 2025.09 | 연합뉴스 팩트체크 (대기업 계열사·공기업 14곳) | 9곳이 자소서 AI 표절률 확인(8곳 감점, 1곳 탈락). 문장 교정은 5곳 허용, 2곳은 AI 사용 금지. 다른 지원자와 내용이 겹치면 감점 |
| 2024.03 | 고용노동부 2023년 하반기 조사 (500대 기업 315곳) | 챗GPT 자소서에 64.1%가 부정적, 확인되면 감점 42.2%·불합격 23.2% |

**AI 탐지기는 틀릴 수 있습니다.** OpenAI는 자사 탐지기가 AI 글의 26%만 잡고 사람 글의 9%를 오판해 2023년 7월 서비스를 종료했습니다. 스탠퍼드 연구에서는 탐지기 7종이 비원어민의 영어 에세이 절반 이상(평균 61.3%)을 AI로 오판했습니다. 한국어 탐지기의 정확도를 독립적으로 검증한 공개 자료는 찾지 못했습니다. 그러니 탐지기 점수를 낮추는 요령보다, 내 경험이 드러나는 글을 쓰는 데 집중하세요.

### 11. 제출 전 체크리스트
[인터랙티브] 체크박스 + 진행 표시 + 저장 + 모두 지우기
- 공고의 작성 유의사항(블라인드, AI 활용 안내, 글자수)을 지켰다
- 문항의 핵심 키워드와 하위 질문에 빠짐없이 답했다
- 소제목과 첫 문장만 읽어도 내용이 전달된다
- 경험이 지원 직무와 이어진다는 문장이 있다
- 행동 부분이 가장 길고, 내가 한 일이 구체적이다
- 숫자에 기간·모수·비교 대상이 붙어 있다
- 추상어(열정·소통·성실)에는 모두 사례가 붙어 있다
- "왜 이 회사인가"에 내가 조사한 사실이 들어갔다
- 모든 내용이 사실이고, 꼬리질문에도 답할 수 있다
- 회사명·직무명·맞춤법을 확인했다
- 소리 내어 읽었을 때 내 말투로 들린다
